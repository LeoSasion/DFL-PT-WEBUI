# Best Training Faceset：原生 WebUI 使用流程

更新日期：2026-10-07。进入「工具 → 质量方案 → 最佳训练人脸」，选择 SRC 或 DST。原始 aligned 仍可直接用作训练输入，筛选并非每个项目的强制步骤。完整流程与恢复说明见 [用户指南](USER_GUIDE.md)，本轮真实操作及范围见 [验收记录](UX_ITERATION_ACCEPTANCE_20261007.md)。

## 1. 确认人物，分析并生成

1. 从当前 aligned 缩略图勾选 1–32 张清楚的「同人参照」，可以包含不同角度。确认后勾选「已确认所选…属于同一目标人物」。同人参照用于定义目标身份，与人工保留决定分别记录。
2. 设置「推荐数量上限」，点击「分析并生成选集」。已有未完成计划显示「继续分析并生成选集」。这会依次建立计划、分批分析全量人脸、生成代表性选集，不自动发布副本或启动训练。
3. 查看全量进度、剩余数量和当前批范围：每批最多 500 张，图片浏览每页 60 张，配对特征计算块最多 250 张。只有全量特征齐全才能全局选择，数量始终是上限；多样性增益不足时提前停止，不为凑数补入大量相似正脸。

选择在全数据集上考虑姿态、眼口几何状态、SFace 相似度和可靠时间信息，质量用于底线与同类择优。「选集记录与详细控制」保留历史、仅建立计划、分析全部、只分析下一批和重新生成等操作。没有确认身份时，也可在详细控制中先分析素材；身份不确定的素材进入 `review/`。

「高级信息与研究对照」保留评分依据和研究选项，生产使用默认评分。研究对照结果不能发布为生产训练选集。

## 2. 草稿恢复与后台结果

未提交参照、确认状态、最近选集、分类、页码和数量偏好按项目及 SRC/DST 自动保存。离开前等待「草稿已自动保存」。切回页面或重启服务后查看恢复提示；计划保存于当前项目 `.webui/best-facesets/`，未完成批次可以继续，不会自动发布。

来源或参照变化时，旧身份确认不会恢复。原素材失效的历史结果只能查看，应「新建选集」并重新确认人物。其他窗口修改同一草稿时，保存暂停；用「重新读取项目草稿」核对最新内容再继续。查看另一历史版本不照搬当前身份确认，可按提示「载入此选集的参照，重新确认」。

离开页面不停止后台处理。终端上方结果栏提供最新结果的「查看结果」；主动展开「最近结果」最多查看三项，异常或未完成项可「查看并继续」，定位到正确项目、侧别和选集。Esc 收起最近结果并还焦；跨项目仍遵守切换保护。

## 3. 人工复核另存新版本

结果支持全量分类分页、放大和理由查看。点击「建立人工复核版本」，对新版本执行「保留」「排除」「暂缓」或批量决定；「撤销上次决定」恢复最近误操作。原算法建议、原选集和旧发布记录保持可查看。

页面分别显示待处理、暂缓、质量达标备选、已决定。质量达标备选不全部计入必须处理的待办。同人参照不等于保留决定，无法读取、缺少有效训练数据等硬约束不能被普通「保留」绕过。

放大复核支持上一张/下一张、左右键跨页；K 保留、X 排除、S 暂缓，Ctrl+Z 撤销，Esc 关闭并还焦。这些操作只在对应复核上下文生效，输入文字时不触发快捷决定。多个窗口同时修改版本时先读取最新版本再继续。

## 4. 预演并保存独立副本

核对人工决定和分类后，先「预演发布并检查原素材」，再明确点击「保存三类独立副本」。人工决定或版本变化后，旧预演不能继续授权保存，应重新预演。新版本另存，不能就地改写已发布版本。

发布目录位于当前项目的 `data_src/best-training/` 或 `data_dst/best-training/`，每个独立批次包含：

- `selected/`：推荐直接用于训练的子集。
- `review/`：身份、质量、几何状态的边界情况，以及当前子集无需加入的质量达标备选。
- `rejected/`：明显错误、低价值重复。
- `receipt.json`：全量成员、分类、理由、原图哈希和副本校验记录。

生成选集后再更改同人参照或取消确认，会使当前确认与旧选集不一致，预演与发布暂停。未发布算法计划可重新生成；人工修订或已发布版本可载入该版本参照并重新确认，或新建选集。发布请求核对生成时的确认参考，不能将屏幕上的新参考与旧结果混用。

发布复制原始 JPEG 字节、DFL 元数据及已有 `.landmarks.json` 辅助记录，不重编码、不删除源 aligned。使用推荐 `selected/` 时，训练预检只认可当前项目中完整发布的选集，核对三类副本的哈希、辅助记录、成员数量，并拒绝未登记的新文件。原始 aligned 仍沿用原输入检查。

## 5. 明确采用 SRC/DST 输入与撤回

点击「在训练配置中使用 selected」保存该侧的项目选择，另一侧选择保留，并进入训练输入确认流程，不启动训练。在「项目采用的人脸集」分别核对 SRC、DST 的来源、数量、版本和有效性，点击「将两侧选择填入本次配置」才改变本次输入。

已有模型的检查点配置不会被项目偏好自动覆盖；提出更换输入后仍需完成配置差异及采样状态确认。选集撤回、原素材变化、文件缺失或未完整发布时，保存的推荐引用明确失效，需要重新检查或主动改用有效选集/原 aligned。

「检查撤回发布 → 撤回推荐并保留副本」会把独立批次的三类副本保存在批次内的 `withdrawn/`，原 aligned 保留，已撤回的批次不再可用作推荐训练输入。副本被手工修改、缺失或加入新文件时，撤回检查报告冲突，保留所有素材等待人工处理。

## 质量模型与证据范围

生产默认为「既有综合质量（Tenengrad 为主）」。质量分是图像质量指标，不是身份概率或准确率。Efficient-FIQA 是唯一新质量评测候选；本次盲评没有显示替换收益，其计划仅供对照，不可发布为生产推荐训练子集。不列入其他 FIQA 候选。

TUFA 状态是关键点几何分组，不能作为真实表情标签。SFace 需要人工确认的同人参照，不能把最大簇直接认定为正确身份。时间去重只在原帧和时间信息通过来源校验时使用；没有合格时间信息时依靠姿态、几何状态和相似度控制重复，不猜测时间戳。

硬过滤与全局选择的功能验证不等同最终训练视觉质量证明。本次不修改 ME 训练桥接，不运行长训练或双 GPU 验收。
