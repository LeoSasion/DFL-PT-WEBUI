## 建议

采用 TAEQI2.1，encoder 始终冻结并使用 `no_grad`。decoder 默认冻结，配置建议明确提供 `frozen`、`tail`、`full` 三种范围。初次训练先验证冻结模式；有可重复的细节不足时，优先尝试只微调末端。全量解冻作为高级实验选项，不作为默认配置。

TAEQI2.1 是确定性的轻量 AE，使用 Qwen-Image-2.1 的潜空间接口，不需要扩散模型或文本编码器。它有 64 潜通道、16 倍空间下采样，原生处理 RGBA。输入普通 RGB 时补 alpha=1；输出 RGB 用于人脸图像，原生 alpha 不作为人脸分割遮罩。人脸遮罩继续使用独立监督头。

保留 LIAE 的独立 AB/B 分支和源/目标/交换路由。LIAE 提供结构约束，不构成身份与表情已完全解耦的证明。不给原始目标 latent 增加直通输出的残差跳连，避免形成绕开中间层的复制路径。

## Inter 原型

当前中间层先卷积，再自适应平均池化到 4×4，压成 128 维全局向量，展开 4×4 后一次双线性放大。它为换脸提供全局瓶颈，但早期池化和较窄瓶颈可能限制局部结构。此处是结构假设，不能认定为上轮模糊的唯一原因。

针对 256 的候选结构：

1. 两个独立 Inter：64×16×16 latent → 两级带步长卷积 → 96×4×4 → 256 维全局瓶颈 → 96×4×4。
2. 在低分辨率完成 LIAE 拼接、融合；再用两级 resize+卷积和残差块学习上采样，4×4→8×8→16×16。
3. 最后投影至 64 潜通道，交给 TAE decoder；保留独立 mask head，无原始 latent 直通路径。

| 256 配置 | 非 AE 学习头总参数 | AB/B 单分支参数 | 全局瓶颈 |
|---|---:|---:|---:|
| 旧结构改接 64 潜通道，hidden=170 | 5,420,789 | 1,839,698 | 128 |
| 新候选，hidden=96 | 3,131,761 | 1,259,584 | 256 |

新候选学习头参数减少 42.2%，全局瓶颈维数增加一倍。缓存输入 latent 后，SRC/DST 两侧学习头+冻结 decoder+反向的短探针中位耗时分别为 34.56/32.48 ms，波动范围有明显重叠，不能据此认证稳定加速。两种结构所有学习参数的梯度均有限。新候选尚未进行学习，未证明画质、换脸身份或收敛优于旧结构。

该原型使用与分辨率绑定的种子网格，不能声称所有尺寸均为 313 万参数：256/448/640/832 时分别为 3,131,761 / 6,382,129 / 11,405,425 / 18,201,649。第一轮应固定 256，比对结构收益后再确定大尺寸预设。原 H3 的 256 块、64 重叠规则不适用于 TAE；TAE 的原生要求来自 16 倍下采样。

采用新候选时，冻结/末端/全量模式的总可训练参数分别约 313 万、369 万、1078 万。不能把这三种配置宣称为等参数对照。

## 解冻策略与实现要求

decoder 解冻可以适应具体人脸与 Inter 的输出分布，也会增加过拟合、潜空间语义变化和收益归因困难。重建误差下降本身不能证明换脸身份更好。先训练 Inter、再有界地比较末端微调，是优先建议；全量解冻需单列比较。

建议 decoder 使用独立 optimizer 参数组，微调初始学习率先取 Inter 的 0.1 倍，作为待验证起点而非已证实最优值。encoder 永远排除于 optimizer，并持续核对冻结边界。模式变化通过明确的保存/恢复或新阶段记录进行，不允许运行中静默切换。

当前代码把整个 `vae.*` 同时排除于 optimizer 和 checkpoint，并在 encode/save/resume 时断言全 AE 冻结。因此不能仅增加前端开关：必须拆分 encoder 与 decoder 的约束，保存所有已更新 decoder 权重和 Adam 状态，记录 codec/结构版本、原始权重 SHA、更新范围与学习率，并验证恢复后的预测一致。旧 H3 checkpoint 继续按原架构读取，不能误载到 TAE。

下一步接入和验证顺序建议：冻结 AE 的完整保存/恢复/合成链路 → 固定 256 的旧/新 Inter 有界对照 → 根据具体弱项比较末端微调。暂不同时增加 GAN、身份网络和多种新损失，以免无法判断改动的作用。
