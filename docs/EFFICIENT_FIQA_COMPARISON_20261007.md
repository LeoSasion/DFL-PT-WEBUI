# Efficient-FIQA 与现有质量分的有限对照

本轮只评测 Efficient-FIQA 的 EdgeNeXt-XXS student，停止增加其他 FIQA 候选。
它评估图像感知质量；本轮不把分数解释为身份可靠性、关键点标注准确率或最终训练收益。

评测素材位于忽略目录 `workspace/.vision-evaluation/efficient-fiqa-20261007`。
8 张真实 aligned 原图：6 张来自此前已验证的外部素材中相隔较远的帧，访谈 SRC / DST 各 1 张。
多个验收目录中的同一素材拷贝没有被算作独立源。姿态和光照有所覆盖，视频来源仍有限。
每张原图有 7 个可控像素退化：轻微、中度、严重模糊，噪声，JPEG 压缩，偏暗和过曝。
共 64 个案例。原始文件只读，逐项 SHA-256 核验；副本保持原始字节，匿名评判图保存无损 PNG。

`tools/efficient-fiqa-benchmark.py prepare --sources-json <只读原图清单.json>` 创建固定随机匿名映射、全脸及眼口细节面板，锁定 protocol、manifest 和 key。
原图清单保存在忽略的评测目录，脚本不包含本工作站的私有媒体绝对路径。
`score` 用现有 `quality_review` 综合分与 Efficient-FIQA 同时评分并封存，关闭每批模型 worker。
现有分包含前景 Tenengrad、曝光、源分辨率和对齐一致性；主比较采用同源图片的排序，避免把分辨率/元数据差异误当模型收益。
Efficient-FIQA 采用固定官方权重、student 图和官方预处理，不更新主进程原有 timm，不训练，不下载额外模型。

由用户指定的 GPT-6 Astra low 独立查看 `blind/`，每项评 0–4 分，0.5 步长，允许并列。
不显示评分模型、模型分数、退化名称或原图位置，不因侧脸、闭眼、张嘴本身扣质量分。
训练可用性作为辅助观察；控制退化的先验方向不当作人类视觉准确率标签。

“明显收益”的规则已在视觉评判前锁定：平均同源 Spearman 提升至少 0.10、同源非并列视觉图片对的排序一致性提升至少 0.10、至少 2 组改善 0.10、变差 0.10 的组最多 1 组、探索性按源 bootstrap 的 95% 下界大于 0，且不能把严重模糊/过曝排在原图前而现有指标和视觉评分都选择原图。
这些是务实的预先约定门槛，不是总体统计证明；同源帧可能相关，bootstrap 也不代表独立视频的泛化置信度。
没有明显收益则继续用现有质量分，把生产升级集中在多样性选集。

`tools/efficient-fiqa-reveal.py --review-sha256 <独立评判已锁定的SHA>` 校验完整 64 项评分和原始锁后揭盲。
该脚本不会自动锁定评判文件，也不允许覆盖已有揭盲结果。视觉结果锁定前不得据模型分数改门槛或做最终裁决。

## 锁定评判后的结果

结论：**本轮没有明显收益，Best Training Faceset 的生产默认继续使用现有 `quality_review` 综合分（×100 展示），不新增生产评分模型。**
Efficient-FIQA 保留为显式评测入口；本轮不会因为未通过而追加其他 FIQA 候选。
这个结论说明当前证据不足以替换默认，不说明 Efficient-FIQA 在所有人脸素材上都更差。
本轮把完整的可控退化集同时交给两个评分器，属于硬过滤前的质量排序对照；没有证明经过 YOLO / TUFA / 像素硬过滤后两者的生产收益完全相同，也没有事后挑选“通过过滤”的子组改变预定裁决。

| 预先固定的比较项 | 现有综合分 | Efficient-FIQA | 结果 |
| --- | ---: | ---: | --- |
| 平均同源 Spearman | 0.5592 | 0.5185 | 差值 −0.0407，未达 +0.10 |
| 平均同源非并列视觉图片对的排序一致性 | 0.7353 | 0.7251 | 差值 −0.0101，未达 +0.10 |
| Spearman 改善至少 0.10 的源组 | — | 2 / 8 | 达到这一个条件 |
| Spearman 变差至少 0.10 的源组 | — | 5 / 8 | 超过最多 1 组 |
| 探索性按源 bootstrap 的 95% 差值区间 | — | [−0.2630, 0.2250] | 下界未大于 0 |
| 预定严重模糊 / 过曝倒置否决项 | — | 0 | 没有触发；其他条件仍未达到 |

完整分组结果保存在 `reveal.json`。当前算法在两张较暗的访谈图 G07 / G08 上排序很弱，Efficient-FIQA 对这两组的排序有所改善。
六张较清晰且分辨率较高的源图中，Efficient-FIQA 有五组相关性下降至少 0.10。
这只是本轮来源、分辨率和内容共同变化的观察，不能据此断定模型差异由某一个因素造成，也没有据此重设门槛或挑选子组宣称通过。

失败案例同样需要保留：Efficient-FIQA 在 G01–G08 中均把偏暗退化放到很靠前的位置，G05–G08 甚至把它排在原图前；视觉评分把这些偏暗图评为 1.5，训练可用性为边界情况。
现有综合分也并非准确的感知质量标尺：8 / 8 组至少有一种退化的分数严格大于原图分数（`>`，并列不计入），主要是轻微模糊、JPEG 压缩，G07 / G08 则是过曝；综合曝光项并不保证排除局部脸部细节被高光擦除的问题。
这些既有缺点支持继续使用像素 / YOLO / TUFA 的明确坏图过滤，并让质量只负责同类可用图片之间的优先级。
本轮没有根据这 64 个案例重新训练、拟合权重或标定阈值，也没有把视觉相关性当作身份、标注或训练准确率。

GPT-6 Astra low 实际查看了 8 张完整匿名面板，并补看 4 张原尺寸匿名图片。
评判文件含 64 项完整评分，已先封存后揭盲，未读取 key / 模型分数；报告中的这些过程事实以独立评判记录为依据。
一次独立计算复核使用带并列的平均秩、秩的 Pearson 和穷举图片对，8 组数值均与揭盲脚本一致，容差 1e-12。
8 个原始文件及原字节副本全部 SHA 核验一致，没有训练、删除或改写原件。
