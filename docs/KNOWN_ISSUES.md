# 预览版已知限制

本页区分现有开发证据与尚待用户反馈的范围。

| 项目 | 当前状态 |
|---|---|
| 新用户安装与便携运行 | 已提供安装脚本、依赖、发布清单和恢复入口；具体干净环境功能表现等待用户实测。 |
| 单卡 ME | 已有短程保存、退出、恢复、有限预测和损失下降证据；不同显卡、驱动、内存配置仍需反馈。 |
| 双卡 | 仅初步 DataParallel 代码；真实梯度同步、稳定性、显存与吞吐未验证。当前不执行双卡测试。 |
| 正式案例与最终画质 | 未宣称合格；小模型损失下降不能证明身份、自然度或时间连续性。旧真人样本画质记录保持原结论。 |
| DeepFaceLive | 已有 DFM 及带两处 Qt 兼容修正的离屏、热身后视频输入技术证据；原版未修正 GUI、真实摄像头和冷启动实时表现未验证。DeepFaceLive 不是本便携包中的应用。 |
| 预训练 XSeg | 官方通用 WF 推理权重已随源码包和便携包提供，并核对完整张量及转换散列；具体素材的遮罩质量等待用户反馈。原始训练状态与优化器不随包，项目专用遮罩可自行标注和训练。 |
| aligned 预览与清洗 / XnViewMP | 默认使用 WebUI 的 SRC/DST 人脸浏览器、图层检查与隔离恢复，无需安装 XnViewMP；已有外部程序可选配置。 |
| 相似图审查 / VisiPics | 当前 `main` 的原生工具可选每批最多 500 张，或比较两批各最多 250 张；只覆盖选定范围，不是自动整库查重。分组可能经其他图片间接连通，需人工复核并保留代表图，见[使用说明](SIMILARITY_REVIEW.md)。0.1.1-preview 原发行包仍只预检前 500 张，无需另装 VisiPics。 |
| 关键帧结果传播 / EbSynth | WebUI 尚未实现，列为后续原生功能候选；场景检测和分段提帧不能替代。仅保留已有外部程序的可选适配入口。 |
| 图像 API（当前 main） | 一键启动器的新安装包含此功能，0.1.1-preview 原发行包尚不包含。奇智编辑、增强和参考图合成为提示词服务；没有公开遮罩参数，不保证精确局部编辑、身份或时间连续性。人工几何图的真实上传、生成、查询与下载通过；当次成功响应暂未返回最终费用。损坏或缺失的本地结果只恢复原任务，临时链接过期后不保证可下载。人脸与视频质量未验收；说明见[图像服务](IMAGE_SERVICE.md)。 |
| 版本与升级 | 新源码应用为 0.1.2-preview，启动器为 0.1.3-preview；固定源码提交及 ZIP SHA-256 见 `release/source-pin.json`。主动升级先保留原源码/构建/依赖备份，失败回退；运行中的任务或项目进程阻止修复/升级。Git 工作副本需使用经审查的固定公开提交，不由启动器覆盖历史。旧 0.1.1-preview 便携包仍是旧功能集，本轮没有宣称其更新。 |
| 自动更新与签名 | 自动更新继续关闭；主动升级采用固定提交及 SHA-256 校验，没有 Windows Authenticode 或签名更新通道声明。 |
| 便携 venv | 项目入口会修正 `pyvenv.cfg`；直接使用项目内 `python.exe`，原 venv 激活脚本可能保留构建目录。 |

如果遇到表中范围之外的错误，或有可复现的安装、保存、停止、恢复问题，请提交 [Issue](https://github.com/LeoSasion/DFL-PT-WEBUI/issues/new/choose)。当前开发验证保持小模型和一小时以内的训练总预算，不为反馈复现启动长训。
