# 0.1.0-preview

首个公开 Windows x64 预览版，面向用户安装、使用和实测反馈。

## 提供的内容

- ME/PyTorch 本地训练、预览、检查点保存、独立 Trainer 监督、Web 重连、停止、备份和恢复。
- 目录、PAK、ZIP 和自定义人脸集读取及固定离线评测；RG、FP16 和 CPU optimizer 的配置与性能记录。
- 数据提取、人物整理、质量检查、XSeg 标注/训练、合成、视频导出和 ONNX DFM 导出。
- 源码安装入口与便携包：独立 Python/Node/FFmpeg、辅助权重、前端构建及相应许可。
- 按 Git 源码快照和运行材料白名单构建发布文件，附逐文件 SHA-256/大小清单、分卷索引和恢复脚本。个人材料、模型、运行状态、日志和旧截图不随分发。

## 已有证据与当前范围

现有开发记录覆盖独立 Trainer 控制和重连、备份恢复、数据格式一致性和性能画像。最新小参数单卡模型为 64px、batch 2；含加载、保存、退出和两轮恢复，总跨度 14 分 41 秒，保存到 15814 轮，首尾损失下降 87.82%。这是功能与收敛趋势证据，详见 [短程报告](ME_SHORT_RUN_ACCEPTANCE.md)。

本次交付只做脚本静态检查、构建及发布包完整性检查；没有追加模型训练、双卡或新环境功能验收。新用户环境与具体功能表现等待实测反馈。正式画质和正式案例另行开展，不把历史未通过的画质记录改为通过。

## 升级与反馈

在线自动更新未启用，通过 [发行页](https://github.com/LeoSasion/DFL-PT-WEBUI/releases/tag/v0.1.0-preview) 下载新版本。新旧版本使用独立目录；先保存停止任务并备份工作区，再进行数据迁移。

使用问题见 [已知限制](KNOWN_ISSUES.md)，反馈见 [FEEDBACK.md](FEEDBACK.md)。版本仍为 preview，欢迎报告可复现问题。
