# 相似组复核

当前 `main` 源码提供分批复核；一键启动器的新安装获取该源码。现有 0.1.1-preview 发行包保持原来的前 500 张预检。

在“工具实验室 → 数据审计 → 相似组清洗”选择 SRC 或 DST：

1. “单批检查”按文件名顺序每批最多分析 500 张，可用上一批、下一批或批次编号查看后续素材。页面显示实际范围、总量与无法分析的数量。
2. “两批比较”每批最多 250 张，选择不同的 A/B 批次，合计仍不超过 500 张；仅显示同时包含两批图片的候选组。数据量不超过 250 张时不提供此模式。
3. 调整相似阈值并人工检查候选。代表图不能选入隔离，可逐张选择或“选中非代表图”。“查看”定位到数据集中的对应素材。
4. 点击“移入可恢复隔离区”，复核所选文件并确认。服务再次核对项目、SRC/DST、阈值、批次与素材指纹；素材变化会阻止旧复核。切换分析上下文会立即清空旧选择。
5. 同一批隔离使用一个恢复令牌，可在数据集的恢复区还原。遇到同名新文件时不覆盖它，保留恢复记录。响应失联时先“检查隔离结果”，读取失败或移动仍在进行时保持待检查状态；不会自动重复提交。

候选来自本地 DCT、色彩及边缘描述子，不上传素材，不进行身份识别。分组使用达到阈值的图片关系连通，因此部分组员可能只经另一张图片间接连接；组内最低分可能低于阈值，需人工复核。

切批只覆盖当前选定范围；两批模式只覆盖选定 A/B 的关系，不表示已经比较整个素材库。无需安装 VisiPics。
