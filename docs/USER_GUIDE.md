# DFL-PT-WEBUI 用户指南

更新日期：2026-10-07。本指南对应已实现并完成本轮隔离功能验收的流程；实际范围、跳过项和真实缩放限制见 [本轮验收记录](UX_ITERATION_ACCEPTANCE_20261007.md)。独立发行验收随 v7 外部报告记录（该文档不自证包 SHA）。

## 1. 打开项目，认识完整流程

运行项目目录中的 `启动 WebUI.bat`，等待服务连接和项目素材读取完成。点击页面标题处的项目入口，可以查看当前项目、选择已有项目或新建项目。新建时先核对名称和目录预览，再明确选择是否切换过去。

每个项目分别保存素材、模型、选集和操作草稿。「项目」决定当前素材归属；「素材管理」用于处理当前项目里的视频和文件。切换前若有运行任务、恢复操作或未保存的遮罩修改，先按页面提示完成保存或停止。

左侧按 **预处理、训练、后处理** 分组，可直接进入任一组。已有处理好的 PAK / aligned 时，直接打开「训练 → 模型训练」，在配置中选择人脸集所在目录；无需从视频导入开始。

顶部流程随页面切换：预处理页显示「素材 → 提帧 → 切脸 → 清洗 → 遮罩 → 训练」；训练总览、模型训练和质量诊断页只显示「预处理 → 训练 → 后处理」；后处理页显示「训练 → 合成 → 封装」。通用工具与设置位于侧栏底部。训练总览内只展示训练与评估操作，项目状态刷新不会自动跳回视频预处理。

SRC 是提供来源人物的人脸集，DST 是目标视频及其中待替换的人脸。已有提取好的人脸目录 `aligned` 可以继续使用；最佳训练人脸筛选是可选方案。

## 2. 准备素材与人脸

1. 在「素材管理」核对 SRC、DST 的归属和文件，再配置相应的视频提帧。
2. 在 SRC、DST 数据页配置切脸，完成后用原生人脸查看器检查人物、裁切、关键点和坏图。
3. 按需要使用人物确认、排序、修复或相似图复核。分析时看清本次范围：单次最多 500 张；配对比较每批最多 250 张。

数据审计中的「通过基本校验」和「需关注」可以重叠：一张图片可能可读取、具备基本数据，同时仍有需要复核的问题。基本校验不代表人物已确认或已经选入训练集。

从具体的「提取」「合成」「导出」等动作进入时，任务窗口直接显示该动作的参数；可以用「更换任务」切换。全局「新建任务」先显示任务选择。核对输入、输出和摘要，完成预检后再明确启动。

## 3. 可选：建立最佳训练人脸选集

进入「工具 → 质量方案 → 最佳训练人脸」，选择 SRC 或 DST。

1. 从缩略图勾选 1–32 张清楚的「同人参照」，可以包含不同角度。确认它们确实属于目标人物，再勾选「已确认所选…属于同一目标人物」。参照用于确认身份，和人工保留决定分别记录。
2. 设置「推荐数量上限」，点击「分析并生成选集」。数量是上限；重复过多时可能提前停止。
3. 查看全量分析进度和当前范围。每批最多 500 张，浏览每页 60 张。离开页面后任务仍可继续；返回已有计划可点「继续分析并生成选集」。
4. 查看推荐训练、待复核或备选、排除三类结果，并按需要放大图片检查理由。

「选集记录与详细控制」可打开历史、逐批分析和重新生成。「高级信息与研究对照」保留评分说明与对照功能，日常操作可沿用默认评分。研究对照结果不能直接发布为训练输入。

参照、数量偏好、最近选集、分类和页码按项目及 SRC/DST 自动保存。离开前等到「草稿已自动保存」；返回时查看恢复提示。若原素材或参照已经变化，需要重新确认人物；旧来源失效的历史结果只能查看，应新建选集。

## 4. 人工复核并保存新版本

在生成的结果中点击「建立人工复核版本」。新版本保留原算法建议和原发布记录。

1. 对当前图片选择「保留」「排除」或「暂缓」，也可以勾选本页图片后批量决定。
2. 用「撤销上次决定」恢复最近一次误操作。页面分别显示待处理、暂缓、质量达标备选和已决定数量；质量达标备选无需全部处理成待办。
3. 放大查看时，左右键切换图片，K 保留、X 排除、S 暂缓，Ctrl+Z 撤销，Esc 关闭。快捷键在对应复核窗口内生效，输入文字时不触发决定。
4. 完成检查后先点「预演发布并检查原素材」，核对数量，再点「保存三类独立副本」。复核变化后需要重新预演。

无法读取或不符合训练输入要求的图片不能人工保留。另一个窗口修改了同一草稿或版本时，先重新读取最新内容再继续。

保存后的批次包含 `selected`（推荐训练）、`review`（待复核或备选）和 `rejected`（排除）三类独立副本，原始 aligned 全部保留。更改参照后不能继续发布旧结果；可「载入此选集的参照，重新确认」，或新建选集。

需要撤回时，先点「检查撤回发布」，通过后点「撤回推荐并保留副本」。撤回保留原件和副本，但该选集不再作为可用推荐训练输入。若副本被修改、缺失或新增文件，先处理页面报告的冲突。

## 5. 确认两侧训练输入

打开 ME 训练配置，在「项目采用的人脸集」分别查看 SRC 和 DST。每侧可以选择「原始 aligned」或当前项目已保存的推荐选集，核对数量、版本、参照和路径。

两侧选择分别保存，修改 DST 不会丢掉 SRC。选择结束后，点击「将两侧选择填入本次配置」，才把这对输入用于本次任务。页面上的项目偏好不会自动改写已有模型保存的配置，也不会启动训练。

「在训练配置中使用 selected」会把该侧选集带到训练输入确认流程。使用已有模型时，仍需查看本次输入与已保存配置的差异，并完成页面要求的数据变更或采样状态确认。撤回、素材变化、文件缺失或不完整的选集会明确显示失效原因；先重新检查或选择其他有效输入。

## 6. 训练、保存与恢复

ME 是换脸训练模型。续训时先核对已有模型、上次保存、继承配置摘要、本次输入、设备和运行计划；需要查看完整参数时展开配置详情。修改受保护配置时，沿用页面的确认和状态重置提示。

训练中的预览和磁盘上已有的历史检查点分别记录。需要结束时使用保存并停止动作，等待保存和退出结果，再查看日志及模型记录。若页面提示「本次保存未确认」，先检查恢复点与任务日志，不能只凭任务已结束认定本次训练已经保存。

切换页面不会停止后台任务。终端上方的独立结果栏显示最新处理结果，点击「查看结果」可回到对应项目、SRC/DST 和选集。需要查看历史时主动展开「最近结果」，最多显示最近三项；未完成或异常结果可「查看并继续」。展开后按 Esc 收起，焦点回到展开按钮。切换项目仍需要通过运行任务保护。

## 7. 遮罩的三种用途

进入「XSeg 遮罩」，先选择需要处理的一侧。默认简洁栏显示「手工修正」及「配置自动应用」「配置 XSeg 训练」；展开「查看遮罩用途」可查看三种方式的说明：

- **手工修正**：逐张修正保留和排除区域，保存后检查边缘。已有人工标注与已经应用的遮罩分别显示。
- **自动应用遮罩**：把内置或已选择的 XSeg 遮罩应用到本侧人脸，需要批量更新时使用。
- **辅助 XSeg 训练**：有手工标注且内置遮罩不能覆盖当前遮挡或轮廓时，再配置场景专用遮罩训练。

当前手工修改未保存时，先保存或放弃修改，再启动批量应用或辅助训练。常用编辑动作保持可见，其余动作在「更多」中；「调整查看面板」可以改变查看面板宽度，布局会记住。较矮窗口中编辑区域可滚动，按需展开说明或更多工具。终端可收起，任务异常和等待回答仍需留意。

## 8. 先检查独立合成小样

在「模型应用」中选择可用 ME 模型和 DST 人脸，按中文说明选择合成与遮罩模式。也可以先点「配置合成小样」：

1. 明确选择起始帧及数量，每次 1–20 帧，核对当前合成参数后预检并启动。
2. 完成后查看 DST 原帧、小样合成、小样遮罩三联图；用上一张、下一张逐帧检查。
3. 小样满意后，点击「按相同参数配置全片合成」。窗口继承小样记录中的参数，仍需完成正式合成预检并明确启动。

小样写入当前项目的 `.webui/merge-previews/` 独立目录，不替换正式 `merged` 序列，也不能直接用于全片视频导出。局部小样不能证明整段视频的质量。

正式合成前会重新检查小样对应的模型、素材和参数。如果已经变化，重新生成小样；也可明确解除小样关联后按普通流程重新配置和预检正式合成。

## 9. 诊断与视频导出

质量诊断用于比较趋势，是可选检查。比较需要同一评测样本上的两个可比较快照；只有可生成快照的运行任务才提供该动作。已有模型可以经预检进入合成，无需为了进入合成重新训练或补齐诊断。

「视频导出」优先显示已有成片和生成记录。重新导出时先查看合成帧、遮罩数量和音轨来源：

- 没有合成序列时，先「配置合成」；没有可用模型时，先查看模型与训练配置。
- 合成帧与遮罩数量不一致时，先检查并补齐合成，再导出。
- 合成输入可用时，配置「导出母版与播放版」或展开其他格式；预检还会检查逐帧对应关系、音轨和输出位置。

已有成片仍可查看，即使重新导出所需的输入暂时缺失。RGB 母版适合保存，MP4 播放版适合播放和分享。

## 10. 常见恢复路径

| 页面提示 | 下一步操作 |
|---|---|
| 草稿保存已暂停 | 重新读取项目草稿，核对最新选择，再继续 |
| 原素材已变化 | 保留历史结果供查看，新建选集并重新确认人物 |
| 上次选集已失效 | 检查是否撤回、缺失或变化，重新选择有效输入 |
| 本次保存未确认 | 检查模型恢复点和任务日志，确认后再续训或合成 |
| 小样素材或参数已变化 | 重新生成独立小样，或明确解除关联后重新预检 |
| 至少需要两个可比较快照 | 用可评测运行任务生成快照；已有模型也可继续合成 |
| 合成序列需要补齐 | 核对帧与遮罩，再配置合成；已有成片可继续查看 |
