# DFL-PT-WEBUI launcher validation

The CPython 3.7 / TensorFlow wheelhouse, CUDA/cuDNN payload downloader, BITS and legacy runtime bootstrap tests were retired with those implementations. Their historical pass counts do not apply to this repository.

pt-runtime.Tests.ps1 validates the actual local Python 3.12 / torch 2.9.1 cu128 manifest, rejects old schemas and refuses missing required FFmpeg. repository-identity.Tests.ps1 rejects Git remote URLs while Git updates remain disabled. First installation uses the official source ZIP instead. install-project.Tests.ps1 covers archive identity, bounds and transactional publication; bootstrap-repair-routing.Tests.ps1 covers offline routing, active-task protection and the host's WebUI repair delegation. project-locator.Tests.ps1 and runtime-service-identity.Tests.ps1 isolate the selected PT project and prevent writes through linked output directories. Other retained tests cover generic launcher installation, logs, process execution, dependency repair, payload safety, and workspace handling.

Run tools/run-launcher-tests.ps1 in Windows PowerShell 5.1 with project-local Pester 4.10.1. Package boundary tests use Python's unittest in tools/tests/test_package_launcher.py. The project Node can run launcher/server/tests/*.test.mjs. Native launcher builds are verified separately with build-host.ps1 -NoDownload after preparing the pinned Microsoft WebView2 SDK and launcher UI dependencies; standalone release verification requires a complete UI build, so -SkipUiBuild receipts are rejected.
